# Roman insula cutaway (Blender)

A procedural Blender scene in the style of the "3D history" reels: a Roman apartment block with the
front wall cut away, faceless mannequin figures, warm plaster with exposed brick, and hard sunlight
through barred windows. Everything is generated by `build_insula.py`; there are no downloaded assets.

| Shot | Frames | What happens |
|---|---|---|
| `shop` | 1–120 | Ground-floor bakery: the baker kneads behind a brick counter, a customer reaches for bread |
| `room` | 121–240 | Upstairs room: the tenant sits on a straw bed, oil lamp lit, sun through the window |
| `stairs` | 241–360 | Top-down on the stair: a figure climbs with an amphora on their shoulder |

The output is 9:16 vertical at 30 fps (12 s). Each shot has its own camera, switched by timeline markers.

## Run it

You need Blender 4.2 or later (tested on 5.2). It runs with no window:

```bash
# open and edit it in Blender
blender -b -P build_insula.py -- --save insula.blend

# one still per shot (frames 60, 180, 300), 1080x1920
blender -b -P build_insula.py -- --stills out/

# the whole animation as PNG frames, then encode
blender -b -P build_insula.py -- --anim out/frames --res 1080 --samples 48
ffmpeg -framerate 30 -start_number 1 -i out/frames/frame_%04d.png -c:v libx264 -crf 18 -pix_fmt yuv420p insula.mp4
```

Flags: `--res` sets the width (the height is 16:9 portrait), `--samples` sets the Cycles samples
(denoised), `--step N` renders every Nth frame for quick previews, and `--frames 60,180,300` picks the
stills. Instead of the Blender app you can also use the `bpy` wheel (`pip install bpy`) and run
`python build_insula.py -- ...`.

On a 4-core CPU a 540-wide preview frame takes about 10 s, and a final 1080x1920 frame at 48–64
samples takes about 1–2 min. A GPU is much faster: set `scene.cycles.device = "GPU"` in `setup_render`.

## Where to change things

- **Layout** is set by the constants at the top (`W0/W1/D`, the storey heights `G/H1`, the stair
  position). The room, bakery and stair builders read them, so moving a wall moves its contents too.
- **Figures** are `Figure(...)` objects: ellipsoid limbs on pivot empties. To pose one, pass
  joint rotations in degrees, where negative X means forward for every joint:
  `fig.pose(frame, spine=(-15, 0, 0), shoulderL=(-60, 0, 10), kneeR=(90, 0, 0))`.
  The joints are `spine neck shoulderL/R elbowL/R wristL/R hipL/R kneeL/R ankleL/R`.
  To get better motion, swap in a Mixamo character and its animations. The cameras and set don't change.
- **Materials** are procedural node trees in `build_materials()`. These include the plaster (with
  cracks and fallen-away patches that show brick), opus mixtum piers, plank floors and cloth.
- **Lighting**: the low sun (`build_world`), the stairwell spot behind the barred window, and the
  oil-lamp point light. The look comes from AgX with the Medium High Contrast look.
- **Cameras**: `build_cameras()` holds one dolly per shot. The stair camera tracks the climber's head.

## Turning it into a reel

1. Render the frames and encode them (see above).
2. Record or generate a narration: one line per shot, about 4 s each.
3. Add word-by-word captions and a low drone or lyre bed in CapCut or Resolve, or with the
   repo's `tech-shorts/engine` voice and caption tooling.
