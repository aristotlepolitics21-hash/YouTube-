# Infamous Shorts

Zack D Films–style horror Shorts scripts, one per Infamous episode: vertical 9:16, 60 seconds, four
15-second scenes. Hyper-real 3D with a cold grade and one red accent, creeping push-ins broken by
hard edits, and a looping ending that runs back into the first line.

Each scene has four timed shots tagged with edits (`[RAMP]` speed ramp, `[GLITCH]` RGB-split cut,
`[FLASH]` white flash, `[PUNCH]` zoom punch, `[FREEZE]` freeze-frame with red circle, `[SMASH]` smash
cut to silence, `[SHAKE]` camera shake, `[J]` J-cut), one line of on-screen text, a voiceover sized to
15 seconds (36–42 words) and horror sound design.

Every fact comes from the episode's reviewed long-form `script.json`. The horror is dread and
implication: no gore, and no victims shown being harmed (graphic real atrocity also gets Shorts
age-restricted).

`ALL.md` collects every script in one file (rebuild it with `python3 build_all.py`).
